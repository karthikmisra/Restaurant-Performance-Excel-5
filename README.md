# 🍽️ Restaurant Chain Performance & Sales Analytics Dashboard

An executive-level data analysis and interactive Excel dashboard project analyzing multi-cuisine restaurant sales trends, order volumes, revenue generation, and menu item performance.

## 📊 Project Overview
This project evaluates comprehensive restaurant order data to uncover key operational and culinary insights. Using advanced Excel modeling techniques, Pivot Tables, dynamic KPI blocks, and custom Slicers, this dashboard transforms raw transactional data into actionable business intelligence.

### Key Business Questions Addressed:
1. **Which category is the most ordered?** (Identified **Asian** cuisine as the highest volume driver).
2. **What are the category-wise trends over time?** (Mapped month-over-month order fluctuations).
3. **Which cuisine has menu expansion gaps?** (Discovered high demand density under Asian items, signaling prime opportunity for new product development).
4. **What do high-value orders look like?** (Analyzed multi-item peak tickets reaching up to $197 per order).

## 🚀 Dashboard Features & Components
* **4 Dynamic KPI Summary Cards:** Live calculations for *Total Revenue*, *Total Orders*, *Average Ticket Value*, and *Menu Variety*.
* **4 Interactive Visual Charts:**
  1. *Total Revenue by Category* (Clustered Column)
  2. *Monthly Order Volume Trend* (Line Chart)
  3. *Order Share Distribution* (Donut/Pie Chart)
  4. *Top 10 Best-Selling Menu Items* (Horizontal Bar Chart)
* **Master Slicers:** Connected interactive filter buttons allowing users to seamlessly slice all charts and KPIs by category and date.
